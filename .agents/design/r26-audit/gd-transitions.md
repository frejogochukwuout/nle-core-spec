## Probe artifacts (so W-V doesn't re-chase ghosts)

1. **HTML5 DnD needs synthetic DragEvents** in this harness: `agent-browser drag @src @tgt` (mouse-path drag) does not fire `dragstart` — yet its drop DID land silently once (discovered via the follow-up "Already Dip to Black" toast proving an earlier replace had committed). Reliable recipe: `new DataTransfer()` + `dragstart`/`dragover`/`drop` dispatched with `bubbles:true` on the real testids; toast testid prefix is `shell-toast-<n>`.
2. **The A2 fade-drop "failure" was the locked-track guard** — A2 boots `aria-pressed=true`; a fade row dropped on locked el-7 commits nothing (honest). Use an unlocked lane for fade-body DnD probes.
3. **iframe.html default width < app floor** → the `window-too-small` overlay intercepts hits; `set viewport 1920 1080` first (same note as W-A3).
4. First-instance effect drops are **silent by design** (only ×N duplicates toast — Clip.tsx:335); read the inspector's Effects list to confirm a count-1 stack.
