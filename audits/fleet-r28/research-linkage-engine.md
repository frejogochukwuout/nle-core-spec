## 1. The engine's linked-companion law (the invariants any reimplementation must hold)

### 1.1 The linkage representation

- **L1 (the field).** A clip's link is `Clip.linkedGroupId` (runtime N-clip group). The index `clipsByLinkedGroupId` is built by `buildClipsByLinkedGroupId` (timeline.ts:1309-1326); the reverse index `linkedClipsByClipId` skips singleton groups (timeline.ts:1348-1353).
- **L2 (legacy inference).** Clips with NO `linkedGroupId` but equal `originId + sourceId + from + durationInFrames` are treated as linked — `findLinkedClips` legacy path (timeline.ts:1590-1601), index twin `buildLinkedClipsByClipId` (timeline.ts:1355-1371). Import-compat only; the key includes `from`+`durationInFrames`, so any edit that changes either silently severs the inferred link (the E1-d root).
- **L3 (the closure primitives).** `getLinkedItemsForEdit` (timeline.ts:834-842) = anchor + group when `options.linked` (default **true**; the spec's `syncLinked`, D32.3), else anchor only. `getSynchronizedLinkedItems` (timeline.ts:856-872) narrows to window-synchronized companions (`from`, `duration`, `sourceStart/End`, `speed` all equal) — the desync-safe set slip/slide/roll/rate-stretch consume. `expandIdsWithLinkedItems` (timeline.ts:946-953) is the batch form. 15 public ops carry `options.linked` (grep: 26 `{ linked?: boolean }` signatures incl. private impls).

### 1.2 The fan-out law (per op family — the algorithm source for the port)

- **L4 (delete — removeItems law).** `removeItems` expands ids to the full linked closure (locked companions filtered), removes all, cascade-drops their transitions (timeline.ts:4507-4543; locked filter :4525-4533).
- **L5 (ripple delete).** `rippleDeleteItems`: closure expansion → per-track base shift (deleted-before-me durations) → the shift re-expands over LINKED companions of downstream clips but SKIPS companions on sync-locked non-edited tracks (§6 owns them, timeline.ts:4394-4397) and on locked tracks (:4398-4400) → covered-clip removal with the same filters (:4433-4444) → Phase 2 §6 propagation (timeline.ts:4471-4474) (timeline.ts:4320-4496).
- **L6 (trim).** `trimHead`/`trimTail`: synchronized set = `getLinkedItemsForEdit` minus locked (timeline.ts:2958-2962, :3060-3064); **one tightest clamp across the whole set** (`keepTightestDelta` over every member's source + adjacent clamps, :2966-2983); anchor applies first, companions take the ACHIEVED delta (:2987-3009).
- **L7 (ripple trim).** `rippleTrimItem`: same synchronized set (:3164-3166); same trim to all; start-handle restores original `from` on anchor AND companions (:3222-3236); downstream shift runs per SYNCED track (candidates `from ≥ oldSyncedEnd` or transition-neighbors, :3246-3262); §6 interval/gap propagation after (:3278-3283).
- **L8 (roll).** `rollingTrimItems`: counterpart pair resolved via `getSynchronizedLinkedCounterpartPair` (timeline.ts:3377-3387 — window-matched, one companion track, atomic); **central clamp spans BOTH pairs** (:3389-3418); transition-preservation binary-search clamp (:3430-3446); counterparts take the ACHIEVED anchor delta read back from the right clip (:3467-3491).
- **L9 (slip).** `slip`: synchronized set only (:4986-4992); source delta converted, tightest-clamped across the set (:5004-5013) + transition-preservation clamp (:5025-5032); one commit to all (:5036-5048).
- **L10 (slide).** `slideItem`: one synchronized counterpart (:5154-5160) + ITS OWN neighbors (adjacency-resolved, :5162-5179); participant clamps run over the primary's AND the counterpart's neighborhood (:5181-5199) + preservation clamp (:5209-5242); counterpart branch applies the ACHIEVED delta (:5314-5340).
- **L11 (move).** `moveClip`/`moveItems`: companions shift by the same DELTA (offset preserved), trackId preserved, locked filtered (timeline.ts:4761-4769, :4873-4883). The bridge's OT-side twin derives ABSOLUTE partner targets = element target + pair offset (av-link.ts:172-203) — same semantics, different form.
- **L12 (split + the relink laws).** `splitClip` splits anchor + companions at the SAME frame (timeline.ts:2662-2668); `applySplitBookkeeping` (timeline.ts:805-818) = transition remap (:741-754) + `relinkSplitSegments` (:773-795): **single linked split → BOTH halves keep the original group (D32.4 relink-both-halves); ≥2 linked splits in one op → one fresh group for all lefts + one for all rights**.
- **L13 (insert-edit — the E1 fixed law).** `_performInsertEditImpl` (timeline.ts:5647-5977):
  - Phase 1: target-track straddler split at insertFrame (:5695-5728); a transition-blocked split **aborts the whole op** (empty result, no commit — :5726).
  - Phase 1b: straddling linked companions split at the SAME frame BEFORE any shift (:5730-5782; lock filter :5756; companion abort :5768-5772).
  - Phase 2: shift set = target clips `from ≥ insertFrame` + their linked companions (:5784-5805); **the E1 exclusion strips every clip with `from < insertFrame` — the left half NEVER moves** (:5806-5815, Decision 31.2).
  - Phase 2b (the companion-track gap treatment): a track hosting a SHIFTED linked companion (unlocked, non-sync-locked) rides the gap AS A TRACK — its other clips at/after the frame shift, unlinked straddlers gap-split (:5817-5868).
  - The ≥2-splits relink, PER ORIGINAL GROUP, once, after Phase 2b (:5870-5925) — lefts → one fresh group, rights → another; single-split groups keep the original id.
  - Phase 3 inserts the new clip (unlinked) :5937-5949; Phase 4 propagates the inserted gap to sync-locked tracks, `skipIds`-deduped against the link-follow — never double-applied (:5959-5971, :4241-4279).
- **L14 (overwrite-edit — the E2 fixed law).** `_performOverwriteEditImpl` (timeline.ts:6023-6330): de-overlap loop classifies every target-track overlap (fully-contained → remove; straddle-both → split×2 + remove middle; straddle-start/end → split + remove one half; :6091-6177), recording per-group **fate**: `cascadeGroups` (a member fully removed) vs `trimGroups` (a member split) (:6064-6076). Then the fate-based companion law: `cascade` → companions on other tracks removed whole; `trim` → `carveRegion` splits/trims the companion to mirror the covered span (:6192-6273; lock filter :6261; carve abort :6267-6270); ≥2-splits relink re-pairs survivors BY SIDE (:6283-6302). Blocked splits abort the whole edit (:6179-6182).
- **L15 (composites).** `removeRangesFromClip` collects its own split pairs + the sync-lock companion halves into ONE per-group, per-SLOT relink (`_relinkRangeRemovalSplitSegments`, timeline.ts:8453-8497; batch assembly :8398-8425) — slot = the surviving timeline slice shared across tracks. `duplicateItems` gives copies a FRESH shared group id (:4615-4621).
- **L16 (the seam twin).** The OT-bridge `av-link.ts` implements the same closure as a pure sidecar expansion: symmetry, live-ids-only, order-stable, cycle-free (:26-43); locked partners skipped (:141-153); absolute move targets preserve the pair offset (:172-203).
